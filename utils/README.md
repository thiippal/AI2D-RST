# Convenience functions for processing AI2D-RST JSON

This directory contains convenience functions for loading and converting AI2D-RST annotations.

## Directory structure

| Directory or file     | Description                                                                                              |
|-----------------------|----------------------------------------------------------------------------------------------------------|
| `build_graphs.py`     | Contains a convenience function for loading AI2D-RST annotations as node-link data into NetworkX graphs. | 
| `convert_jit_json.py` | Converts legacy AI2D-RST JIT JSON annotations to node-link data.                                         |
